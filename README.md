# smart_stethoscope
Flutter UI for interacting with the models.  Integration of TFLite models into the app using the Flutter tflite_flutter package.  Assets folder containing all TFLite models.

## Features
- Real-time predictions on heart and lung data based on humans cardiopulmonary signals and emotion detection based on speech.
- Lightweight models optimized for mobile devices.
- Easy integration and updates of TFLite models.
- User-friendly Flutter interface.
